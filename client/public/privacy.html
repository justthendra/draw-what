🔒 Privacy Policy

Draw What?! - Discord Activity

1. Information We Collect

When you use Draw What?!, we may collect:

  • Discord User ID: To identify you in game sessions
  • Username: To display your name to other players
  • Game Data: Drawings, scores, and game progress (temporary, not stored permanently)

2. How We Use Your Information

We use the collected information solely for:

  • Enabling multiplayer gameplay
  • Displaying player names and scores
  • Synchronizing game state between players

3. Data Storage & Retention

We do NOT permanently store any personal data. All game data (drawings, scores, room information) is:

  • Stored temporarily in server memory during gameplay
  • Automatically deleted when the game session ends
  • Never shared with third parties

4. Third-Party Services

This application runs as a Discord Activity and uses:

  • Discord API: For authentication and user identity
  • Render: For hosting the game server
  • Vercel: For hosting the web interface

5. Your Rights

Since we don't permanently store personal data, there is no data to delete or export. Your Discord data is governed by Discord's Privacy Policy.

6. Children's Privacy

This game is intended for users aged 13 and above, in accordance with Discord's Terms of Service.

7. Contact Us

For any privacy-related questions, please contact us through Discord or GitHub.

🔒 Gizlilik Politikası

Draw What?! - Discord Aktivitesi

1. Topladığımız Bilgiler

Draw What?! kullanırken şu bilgileri toplayabiliriz:

  • Discord Kullanıcı ID'si: Oyun oturumlarında sizi tanımlamak için
  • Kullanıcı Adı: Diğer oyunculara adınızı göstermek için
  • Oyun Verileri: Çizimler, puanlar ve oyun ilerlemesi (geçici, kalıcı olarak saklanmaz)

2. Bilgilerinizi Nasıl Kullanıyoruz

Toplanan bilgileri yalnızca şu amaçlarla kullanıyoruz:

  • Çok oyunculu oynanışı sağlamak
  • Oyuncu isimlerini ve puanlarını göstermek
  • Oyuncular arasında oyun durumunu senkronize etmek

3. Veri Depolama ve Saklama

Hiçbir kişisel veriyi kalıcı olarak SAKLAMIYORUZ. Tüm oyun verileri (çizimler, puanlar, oda bilgileri):

  • Oyun sırasında sunucu belleğinde geçici olarak saklanır
  • Oyun oturumu bittiğinde otomatik olarak silinir
  • Asla üçüncü taraflarla paylaşılmaz

4. Üçüncü Taraf Hizmetleri

Bu uygulama bir Discord Aktivitesi olarak çalışır ve şunları kullanır:

  • Discord API: Kimlik doğrulama ve kullanıcı kimliği için
  • Render: Oyun sunucusunu barındırmak için
  • Vercel: Web arayüzünü barındırmak için

5. Haklarınız

Kişisel verileri kalıcı olarak saklamadığımız için silinecek veya dışa aktarılacak veri yoktur. Discord verileriniz Discord'un Gizlilik Politikası kapsamındadır.

6. Çocukların Gizliliği

Bu oyun, Discord'un Hizmet Şartları'na uygun olarak 13 yaş ve üzeri kullanıcılara yöneliktir.

7. Bize Ulaşın

Gizlilikle ilgili sorularınız için Discord veya GitHub üzerinden bizimle iletişime geçebilirsiniz.
